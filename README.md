# 헬린이

헬스 초보를 위한 운동 기록 · 루틴 · 휴식 타이머 웹앱(PWA). 폰 홈 화면에 추가해서 헬스장에서 켜 두고 쓴다.

Hevy, Strong, Fitbod, 플랜핏, 번핏 같은 앱을 조사해서 설계했다. 근거는 [docs/benchmark.md](docs/benchmark.md)에 있다.

## 기능

**시작**
- 질문 3개(운동 경험, 주당 횟수, 헬스장·집)로 프로그램을 추천한다. 무분할, 상하체 2분할, 3분할, PPL A/B(6일 순환), 5×5, 홈트가 있다.
- 루틴은 요일이 아니라 순서대로 돈다. 같은 프로그램에서 추가한 루틴끼리 순서를 지키므로, 하루 쉬어도 다음 차례부터 이어진다.
- 홈에는 이번 주 목표, 연속 주, 다음 차례 "오늘의 루틴"이 있다.

**운동 중**
- `세트 | 이전 | kg | 회 | ✓` 표에 기록한다. 칸을 누르면 큰 숫자 키패드가 뜨고, ±증량 단추와 "다음"이 있다.
- ✓를 누르면 휴식 타이머가 자동으로 시작된다. 하단 바에서 ±15초와 건너뛰기를 할 수 있고, 누르면 원형 타이머로 크게 볼 수 있다.
- 이전 기록을 보여주고, 누르면 그대로 복사된다. 지난번 목표를 채웠으면 증량을 제안한다(누를 때만 적용).
- 지난 기록을 넘으면 그 자리에서 PR 알림이 뜬다.
- 세트 종류(워밍업/드롭/실패), 워밍업 자동 생성, 원판 계산기, 메모, 순서 변경을 쓸 수 있다.
- 종목 바꾸기는 남은 세트만 바꾼다. 이미 한 세트는 원래 종목 기록으로 남고, 원래 종목의 무게를 새 종목으로 옮기지 않는다. 추천은 같은 운동 역할(예: 스쿼트 패턴) → 비슷한 역할 → 같은 부위 순서다. 종목을 잘못 골랐을 때 쓰는 "종목 정정"(한 세트 포함)과 "오늘은 여기까지"(남은 세트 빼기)는 따로 있다.
- 무게 기준(봉 포함 총무게, 한 손 덤벨 무게, 기구 표시 무게)을 종목마다 보여주고, 처음 하는 종목의 무게는 시작 예시라고 알려준다. 지금 할 세트를 강조하고, 화면 밖이면 "지금 할 세트" 버튼으로 돌아온다.
- 플랭크 같은 시간 세트는 ▶로 타이머를 돌리면 끝날 때 자동 완료된다.
- 다른 탭으로 가도 운동은 계속되고, 미니 바로 돌아온다. 새로고침해도 진행 상황이 남는다.

**운동 후**
- "N번째 운동 완료!" 화면에서 시간·볼륨·세트·PR, 이번 주 현황, 오늘 쓴 근육 지도를 보여준다.
- #오운완 공유 카드를 이미지로 공유하거나 저장할 수 있다.
- 기본 루틴 반영은 두 가지로 나뉜다. "다음 목표 올리기"는 기본으로 켜져 있고, 같은 종목에서 무게나 횟수가 오른 경우만 반영한다(낮추지 않는다). "종목 구성도 바꾸기"는 기본으로 꺼져 있어서, 꺼 두면 오늘 바꾼 종목은 오늘만 적용된다.

**기록**
- 운동한 날이 잔디처럼 칠해진 달력과 날짜별 상세가 있다.
- 끝난 기록도 고칠 수 있다(무게·횟수·세트 삭제·종목 정정). 통계와 다음 추천이 바로 다시 계산된다.
- 주간 볼륨 그래프(표로 보기 포함), 최근 7일 부위별 세트와 근육 지도, 부위별 마지막 운동일을 보여준다.
- 종목별로 추정 1RM 추이, 최고 기록, 날짜별 세트를 볼 수 있다.

**종목 라이브러리**
- 81종목이 있다. 부위, 장비, 주동근, 한 줄 자세 팁, 유튜브 자세 영상 링크를 붙였다.
- 초성 검색(ㅂㅊ → 벤치프레스)이 되고, 종목을 직접 만들 수 있다.

**타이머**
- 인터벌(타바타·30/30·40/20·EMOM), 카운트다운, 스톱워치가 있다. 구간마다 화면 색이 바뀌고 3·2·1 신호음이 난다.

**설정**
- 신호음, 진동, 주간 목표, 기본 휴식, 봉 무게를 정할 수 있다. JSON으로 백업하고 불러올 수 있다.

## 폰에서 쓰기

배포한 주소를 폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열리고, 오프라인에서도 동작한다.

- 데이터는 그 기기의 브라우저에만 저장된다(서버 없음). 다른 기기로 옮기려면 설정에서 내보내고 다른 기기에서 불러온다.
- 아이폰 사파리는 홈 화면에 추가하지 않으면 오래 안 쓴 사이트의 데이터를 지울 수 있다. 홈 화면에 추가하고 가끔 백업하자. 운동을 5번 넘게 하면 홈에 백업 알림이 뜬다.
- 아이폰은 무음 모드에서 신호음이 나지 않고, 진동 API를 지원하지 않는다.
- 운동 중에는 화면이 꺼지지 않게 유지한다. 아이폰 홈 화면 앱은 iOS 18.4 이상에서 된다.

## 개발

Node 22 이상.

```bash
npm install
npm run dev        # 개발 서버
npm run typecheck
npm test           # 단위 테스트 (vitest)
npm run e2e        # 브라우저 테스트 (playwright, 처음엔 npx playwright install chromium)
npm run build      # dist/ 에 정적 파일 생성
```

### 구조

```
src/
  data/        종목 라이브러리(exercises.ts), 추천 프로그램(programs.ts)
  lib/         상태(reducer·store·storage), 타이머 계산, 기록·PR·통계, 증량 제안, 공유 카드
  components/  키패드, 시트, 토스트, 근육 지도, 차트, 종목 검색
  screens/     홈, 온보딩, 루틴, 타이머, 기록, 설정, workout/(운동 화면·완료 화면)
  styles/      tokens(색·간격) → base → components → workout → screens
```

모든 타이머는 시작 시각(timestamp)으로 남은 시간을 계산한다. 화면이 잠기거나 탭이 백그라운드에 있어도 돌아오면 정확하다.

## 배포

빌드 결과물은 정적 파일(`dist/`)뿐이라 어디든 올릴 수 있다.

**GitHub Pages (기본)**: `main`에 푸시하면 `.github/workflows/deploy.yml`이 빌드해서 `gh-pages` 브랜치로 내보낸다. 주소는 https://damienmusica.github.io/hellini/ 이다. 레포 Settings → Pages에서 Source가 "Deploy from a branch", 브랜치 `gh-pages` / `/ (root)`로 되어 있어야 한다. 하위 경로에 올리기 때문에 빌드할 때 `BASE_PATH=/hellini/`를 쓴다.

Cloudflare Pages나 Vercel로 도메인 루트에 올릴 때는 `BASE_PATH` 없이 빌드하면 된다.

**Cloudflare Pages**: Workers & Pages → Create → Pages → Connect to Git → 이 레포 선택
- Framework preset: `Vite` (또는 None)
- Build command: `npm run build`
- Build output directory: `dist`
- Node 버전은 `.nvmrc`(22)를 따른다.

**Vercel**: Add New → Project → 이 레포 Import. Vite를 자동으로 인식하므로 그대로 Deploy.

둘 다 `main`에 푸시하면 자동으로 다시 배포되고, PR마다 미리보기 주소가 생긴다.
