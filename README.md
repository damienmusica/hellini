# 헬린이

운동 루틴을 관리하고, 헬스장에서 폰으로 켜 두고 따라 하는 트레이닝 웹앱(PWA).

## 기능

- **루틴**: 종목마다 세트, 횟수(또는 시간), 무게, 휴식 시간을 정해 둔다.
- **운동 진행**: 루틴을 시작하면 지금 할 세트를 크게 보여 준다. 무게·횟수를 ± 버튼으로 고치면 남은 세트에도 같이 적용된다. "세트 완료"를 누르면 휴식 타이머가 자동으로 돈다(±15초, 건너뛰기).
- **시간 세트**: 플랭크처럼 시간으로 하는 종목은 타이머가 끝나면 세트가 자동으로 완료된다.
- **타이머**: 인터벌(타바타·EMOM 프리셋), 카운트다운, 스톱워치. 3·2·1 신호음과 진동(안드로이드)이 나온다.
- **기록**: 끝낸 운동의 시간·세트·볼륨, 종목별로 지난번에 한 무게와 횟수. 오늘 든 무게를 루틴 기본값으로 저장할 수 있다.
- **백업**: JSON으로 내보내고 가져오기.

운동 중에는 화면이 꺼지지 않게 유지하고, 타이머는 시각을 기준으로 계산해서 화면이 잠겼다 켜져도 시간이 밀리지 않는다.

## 폰에서 쓰기

배포한 주소를 폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열리고 오프라인에서도 동작한다.

- 데이터는 그 기기의 브라우저에만 저장된다(서버 없음). 다른 기기로 옮길 때는 기록 탭에서 내보내기 → 가져오기.
- 아이폰 사파리는 홈 화면에 추가하지 않으면 오래 안 쓴 사이트의 데이터를 지울 수 있다. 홈 화면에 추가하고, 가끔 백업해 두자.
- 아이폰은 무음 모드에서 신호음이 나지 않고, 진동 API를 지원하지 않는다.

## 개발

Node 22 이상.

```bash
npm install
npm run dev        # 개발 서버
npm run typecheck
npm test           # 단위 테스트 (vitest)
npm run e2e        # 브라우저 테스트 (playwright, 처음엔 npx playwright install chromium)
npm run build      # dist/ 에 정적 파일 생성
```

## 배포

빌드 결과물은 정적 파일(`dist/`)뿐이라 어디든 올릴 수 있다.

**Cloudflare Pages**: Workers & Pages → Create → Pages → Connect to Git → 이 레포 선택
- Framework preset: `Vite` (또는 None)
- Build command: `npm run build`
- Build output directory: `dist`

**Vercel**: Add New → Project → 이 레포 Import. Vite를 자동으로 인식하므로 그대로 Deploy.

둘 다 `main`에 푸시하면 자동으로 다시 배포되고, PR마다 미리보기 주소가 생긴다.
