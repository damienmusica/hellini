# 디자인 v3 (2026-10-15 디자인 리뷰 반영)

리뷰 결론: 기능 수가 아니라 정보 계층과 조작 경로가 과제. "차분한 운동 기록 도구" — 밝은 중립색 바탕, 진한 본문, 큰 수행 숫자, 제한된 강조색, 짧은 조작 경로. 데이터 모델과 추천 엔진은 그대로 두고 화면만 재구성했다.

## 원칙

- 운동 전에는 오늘의 세션, 운동 중에는 현재 세트, 끝난 뒤에는 실제 수행과 다음 목표를 먼저 보여준다.
- 한 화면의 주요 행동은 하나. 설명은 필요한 순간에 열고, 배운 내용은 반복하지 않는다.
- 색만 바꾸거나 다크 모드·유리 효과를 입히는 식으로 끝내지 않는다. 그라데이션, 발광, 장식용 3D, 모든 정보의 카드화, 임의의 회복 점수는 쓰지 않는다.

## 화면

**홈** — 날짜·작은 앱명 → `오늘 · 프로그램 n/N` → 세션명(32px) → 장소 칩 → 종목 요약·시간·조정 필요 → 운동 시작. 주간 목표는 구분선 아래 작은 줄. 진행 중이면 재개가 유일한 주요 행동(다른 루틴·자유 운동 숨김). 인사말 없음.

**운동 중** — 상단 바(세션명·장소, 경과, 완료). 요약 3칸은 한 줄로 접힘. 처음 종목 안내는 세션당 한 번(`sessionStorage`), 표에는 '시작값' 표식. 현재 종목만 펼치고 나머지는 `이름 · 3세트 · 60kg × 8 · 1/3` 한 줄(탭하면 펼침). 현재 세트는 약한 배경 + 26px 숫자 + 채워진 완료 버튼. 자세 팁은 ⓘ 버튼. 카드 아래 `휴식 · 바꾸기 · +세트`. 휴식 바에 다음 세트.

**운동 변경(한 시트)** — 부제 `완료한 N세트는 유지 · 오늘만`. 사유 칩(사용 중 / 기구 없음 / 다른 운동, 선택). 후보 3~5 카드: 운동명, 장비 · 이유, 지난 수행. `다른 운동 찾기`를 눌러야 검색·전체 목록. 사용 중이면 같은 장비·같은 보조 장비(랙·벤치)를 쓰는 후보를 뒤로. 기구 없음 + 등록 장소면 `이 장소에서는 항상` 스위치. 교체 후 6초 되돌리기(그 사이 세트를 완료했으면 되돌리지 않음).

**장소** — 새 장소는 장비 미확인에서 시작. 프리셋(덤벨 + 벤치 / 기본 헬스장 / 맨몸) 또는 직접 체크. 장비(바벨·덤벨·머신·케이블·스미스·케틀벨)와 보조 장비(벤치·인클라인 벤치·랙·풀업바)를 따로. 종목별 필수 보조 장비는 `REQUIRES`(`src/data/exercises.ts`). 고른 뒤 `시작 전 조정`: 못 하는 종목과 대체안을 한 화면에서 비교, 종목별 `다른 운동`/`그대로`, `N개 바꾸고 시작` 또는 `조정 없이 시작`. 등록 장소면 `기억하기` 스위치. 기본 루틴은 그대로라는 설명은 한 번만.

**종료 시트** — 첫 행동은 `운동 저장`. 그 아래 검토 영역: `오늘 기록을 다음 기본값에 반영`(오늘 더 한 값을 복사; 증량 제안과 다르다고 명시)과 `종목 구성도 바꾸기`(기본 꺼짐).

**완료 화면** — `N번째 운동 저장됨` → 세션명 → `세트 · 시간 · 새 기록` 한 줄 → 볼륨/세트/시간 숫자 줄 → 종목별 결과 → 새 기록 → 이번 주 → 근육 지도는 펼침 → 닫기(주행동), 공유(보조). 카운트업 없음. 컨페티는 PR·기념 회차만.

**기록** — 이번 주 요약 줄 + 최근 30개 목록이 기본. 달력은 `달력` 버튼으로 펼쳐 날짜를 고른다.

**루틴·프로그램** — 카드에 목적(습관·자세 / 근비대 / 근력 …), 회당 약 N분, 필요한 장비.

## v3.1 — 3차 리뷰 반영 (2026-10-15, 종합 개선 리포트)

리뷰 결론: 방향은 유지하고 세부 조작과 추천의 신뢰도를 완성한다.

### P0 대체 적격성 (`src/lib/adjust.ts`, `src/lib/substitutes.ts`)

- **적격성 → 순위 → 세션 검토.** 자동 제안과 후보 카드는 같은 역할 또는 비슷한 역할(`NEAR_ROLES`)만 본다(`strict`). "같은 부위"는 더 이상 유사 대체로 치지 않고 `다른 운동 찾기`의 전체 목록에서만 직접 고른다.
- **세션 전체 중복 금지.** 시작 전 조정은 세션에 이미 있는 종목·다른 자리에 제안한 종목을 다시 제안하지 않는다. 세트 수도 자리마다 그대로라서, 한 종목으로 11세트가 몰리는 일이 없다.
- **후보 없음을 허용.** 적격 후보가 없으면 "현재 장비로 비슷하게 바꾸기 어려워요"로 멈추고, `그대로`(운동 중에 정함) 또는 `오늘 제외`(`session/start` `skips`)를 고른다. 운동 중 교체 시트도 같은 상태를 보여주고 `오늘은 이 운동 제외`를 제공한다.
- 덤벨만 있는 환경을 위해 벤치가 필요 없는 변형 4종을 라이브러리에 추가: 벤트오버 덤벨 로우, 벤트오버 리어 델트 레이즈, 덤벨 루마니안 데드리프트, 덤벨 플로어 프레스. 각 역할 그룹의 마지막 순위.
- 검증(단위·E2E): Pull A + 덤벨만 → 백익스텐션 0회, 페이스풀 → 벤트오버 리어 델트 레이즈, 당기기 세 자리 중 하나만 벤트오버 덤벨 로우, 나머지는 "어려워요".

### P1 운동 설명 (`src/data/guides.ts`, `src/components/GuideSheet.tsx`)

- 기존 ⓘ 진입점을 구조화된 설명 시트로 확장: 한 줄 목적 → 필요 장비(장비 + 보조 장비) → 준비 → 기록 기준 → 쓰는 근육 → 핵심 동작 3단계. 흔한 실수·참고 영상·출처는 펼침.
- 콘텐츠는 기본 프로그램에 든 45종목 + 새 변형 4종. 모두 `reviewed: false`(초안)로 표시하고 시트 하단에 "v2026-10-15.1 · 초안 · 검토 전"을 보여준다. 운동 id와 과거 기록 단위는 바꾸지 않는다.
- 기록 규칙: 장비 기준(`weightBasis`)에 종목별 예외(`record`)와 편측 운동(`UNILATERAL`)을 더한다. 어시스트 풀업처럼 숫자가 클수록 가벼운 보조 중량은 설명에만 적고 증량 계산에서는 다루지 않는다(미구현, 문서화).
- 접근: 운동 헤더 ⓘ, 접힌 운동 행 ⓘ, 후보 카드 ⓘ(카드 선택과 분리, 닫아도 선택되지 않음). 접근 가능한 이름은 `"{운동} 운동 설명"`. 시트를 닫으면 열었던 버튼으로 초점 복귀(`Sheet`). 휴식 중이면 시트 위에 남은 시간을 작게 표시하고 타이머는 계속 돈다.
- 검증(E2E): 설명을 열고 닫아도 입력값·완료 상태·현재 세트·휴식 타이머가 그대로.

### P1 사유 기본값

- 교체 사유는 사용자가 칩을 골랐을 때만 기록한다(`swap.reason` 선택). 시작 전 조정으로 바뀐 종목은 `adjust`("장비 조정")로 남기고, 장소 프로필은 `기억하기` 스위치를 켰을 때만 바뀐다.

### P2 밀도

- '시작값' 표식은 세트마다가 아니라 종목 헤더에 한 번.
- 접힌 운동은 박스 대신 구분선 목록. 상태는 `완료` / `1/3` / `3세트 남음` 문구로.
- 교체 시트는 후보만 보일 때 내용 높이만큼(`auto`), 전체 목록을 열면 전체 높이.

### 이번에도 못 한 것

- 어시스트 풀업 보조 중량의 역방향 증량(→ v0.3.2에서 반영), 특정 머신 인스턴스(모델·저항비) 연결, 잠금 알림(P3 → v0.4에서 최선 노력 알림), 실기기.

## v0.4 — 프리미엄 다듬기 (2026-10-15, 전수 화면 점검 뒤)

모든 화면을 390·320px 라이트·다크로 찍어 점검한 결과, 시각 체계는 유지하고 깊이를 더했다.

### 콘텐츠
- 운동 설명 86종목 전부(`src/data/guides.ts`, v2026-10-15.2). 검토 상태는 `review: draft | edited | expert`로 두고 시트에 그대로 보여준다. 지금은 전부 `edited`(편집 검토: 동작 순서·기록 단위·장비 조건을 라이브러리 데이터와 대조)이고 전문가 검수는 아직이다.
- 검색 별칭(`ALIASES`): 줄임말·다른 표기·영문 약어. 초성 검색은 별칭에도 적용.

### 자기관리: 주간 리뷰 (`src/lib/review.ts`)
- 규칙 기반·결정적. 충족한 조건만 문장으로 만들고, 쉰 날을 처벌하지 않는다(Gentler Streak의 결과 문구 원칙).
- 카드: 숫자 셋(운동 n/목표, 볼륨, 새 기록) + 문장 몇 줄(톤은 점 색 하나). 홈에는 새 주에 한 번(닫으면 `settings.reviewSeenWeek`), 통계에는 항상.
- 첫 주에는 "기록 없음" 리뷰를 띄우지 않는다(지난 주나 그 전주에 기록이 있어야).

### 휴식 끝 알림 (`src/lib/notify.ts`, `src/sw.ts`)
- 설정에서 켜는 순간에만 권한을 묻는다. 화면이 꺼졌거나 다른 앱을 보는 중(`document.hidden`)에 휴식이 끝나면 서비스 워커 알림(아이폰 PWA는 이 길만 됨), 없으면 페이지 알림. 앱으로 돌아오면 치운다.
- 한계를 숨기지 않는다: 앱을 완전히 닫으면 오지 않고, 아이폰은 홈 화면에 추가한 뒤에만. 설정 문구에 그대로 적는다.
- 서비스 워커는 `injectManifest`로 바꿨다(프리캐시 + 폰트 런타임 캐시 + 알림 클릭 시 앱 열기). `tsc -p tsconfig.sw.json`으로 따로 타입 검사.

### 세부
- 완료 화면: 볼륨을 핵심 숫자로, 세트·시간은 보조. "다음 차례 · 루틴" 한 줄.
- 프로그램 태그가 단어 중간에서 줄바꿈되던 것, 종목 메뉴의 "자세 팁 · 영상" → "운동 설명"(ⓘ와 같은 이름), 320px 세트 표의 '이전' 칸.
- 첫 화면에 필요 없는 화면(기록·루틴·설정·완료)은 지연 로딩. 첫 JS 446KB → 335KB.

### 여전히 못 한 것
- 전문가 콘텐츠 검수, 자체 제작 미디어, 특정 머신 인스턴스, 앱을 닫은 뒤의 잠금 알림(서버 푸시 또는 네이티브), 실기기.
