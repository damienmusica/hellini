# 디자인 v3 (2026-10-15 디자인 리뷰 반영)

리뷰 결론: 기능 수가 아니라 정보 계층과 조작 경로가 과제. "차분한 운동 기록 도구" — 밝은 중립색 바탕, 진한 본문, 큰 수행 숫자, 제한된 강조색, 짧은 조작 경로. 데이터 모델과 추천 엔진은 그대로 두고 화면만 재구성했다.

## 원칙

- 운동 전에는 오늘의 세션, 운동 중에는 현재 세트, 끝난 뒤에는 실제 수행과 다음 목표를 먼저 보여준다.
- 한 화면의 주요 행동은 하나. 설명은 필요한 순간에 열고, 배운 내용은 반복하지 않는다.
- 색만 바꾸거나 다크 모드·유리 효과를 입히는 식으로 끝내지 않는다. 그라데이션, 발광, 장식용 3D, 모든 정보의 카드화, 임의의 회복 점수는 쓰지 않는다.

## 토큰 (`src/styles/tokens.css`)

| 토큰 | 라이트 | 규칙 |
|---|---|---|
| 배경 / 표면 | `#FAFAF8` / `#FFFFFF` | 차이는 작게. 카드는 1px 구분선, 그림자 없음 |
| 본문 / 보조문 | `#171B1F` / `#545C63` (6.6:1) | 보조 중 더 연한 `#6B7278`(4.9:1)도 4.5:1 이상 |
| 강조 | `#0B635B` (흰 글자 7.5:1) | 주행동과 선택 상태에만 |
| 구분선 | `#D9DDDF` | 표·그룹 구조. 모든 요소를 테두리로 두르지 않음 |
| 상태 | 완료 초록 / 경고 황토 / 삭제 적색 | 텍스트·아이콘과 함께 (색만으로 구분 X) |
| 모서리 | 입력 8 / 그룹 12 / 시트 20 | 알약은 칩·작은 버튼에만 |
| 글자 | 제목 28~32 / 섹션 20 / 본문 16 / 보조 14 | 핵심 정보 11px 사용 중단 (`.t-overline` 13) |
| 수행 숫자 | 현재 세트 26 / 다른 세트 20 / 휴식 타이머 34 | tabular-nums |
| 터치 | 일반 44 / 주행동 48~56 | 세트 셀·완료 버튼 48, 칩 40, 아이콘 버튼 44 |

다크 모드는 같은 계층을 유지하는 별도 값(`prefers-color-scheme: dark`).

## 화면

**홈** — 날짜·작은 앱명 → `오늘 · 프로그램 n/N` → 세션명(32px) → 장소 칩 → 종목 요약·시간·조정 필요 → 운동 시작. 주간 목표는 구분선 아래 작은 줄. 진행 중이면 재개가 유일한 주요 행동(다른 루틴·자유 운동 숨김). 인사말 없음.

**운동 중** — 상단 바(세션명·장소, 경과, 완료). 요약 3칸은 한 줄로 접힘. 처음 종목 안내는 세션당 한 번(`sessionStorage`), 표에는 '시작값' 표식. 현재 종목만 펼치고 나머지는 `이름 · 3세트 · 60kg × 8 · 1/3` 한 줄(탭하면 펼침). 현재 세트는 약한 배경 + 26px 숫자 + 채워진 완료 버튼. 자세 팁은 ⓘ 버튼. 카드 아래 `휴식 · 바꾸기 · +세트`. 휴식 바에 다음 세트.

**운동 변경(한 시트)** — 부제 `완료한 N세트는 유지 · 오늘만`. 사유 칩(사용 중 / 기구 없음 / 다른 운동, 선택). 후보 3~5 카드: 운동명, 장비 · 이유, 지난 수행. `다른 운동 찾기`를 눌러야 검색·전체 목록. 사용 중이면 같은 장비·같은 보조 장비(랙·벤치)를 쓰는 후보를 뒤로. 기구 없음 + 등록 장소면 `이 장소에서는 항상` 스위치. 교체 후 6초 되돌리기(그 사이 세트를 완료했으면 되돌리지 않음).

**장소** — 새 장소는 장비 미확인에서 시작. 프리셋(덤벨 + 벤치 / 기본 헬스장 / 맨몸) 또는 직접 체크. 장비(바벨·덤벨·머신·케이블·스미스·케틀벨)와 보조 장비(벤치·인클라인 벤치·랙·풀업바)를 따로. 종목별 필수 보조 장비는 `REQUIRES`(`src/data/exercises.ts`). 고른 뒤 `시작 전 조정`: 못 하는 종목과 대체안을 한 화면에서 비교, 종목별 `다른 운동`/`그대로`, `N개 바꾸고 시작` 또는 `조정 없이 시작`. 등록 장소면 `기억하기` 스위치. 기본 루틴은 그대로라는 설명은 한 번만.

**종료 시트** — 첫 행동은 `운동 저장`. 그 아래 검토 영역: `오늘 기록을 다음 기본값에 반영`(오늘 더 한 값을 복사; 증량 제안과 다르다고 명시)과 `종목 구성도 바꾸기`(기본 꺼짐).

**완료 화면** — `N번째 운동 저장됨` → 세션명 → `세트 · 시간 · 새 기록` 한 줄 → 볼륨/세트/시간 숫자 줄 → 종목별 결과 → 새 기록 → 이번 주 → 근육 지도는 펼침 → 닫기(주행동), 공유(보조). 카운트업 없음. 컨페티는 PR·기념 회차만.

**기록** — 이번 주 요약 줄 + 최근 30개 목록이 기본. 달력은 `달력` 버튼으로 펼쳐 날짜를 고른다.

**루틴·프로그램** — 카드에 목적(습관·자세 / 근비대 / 근력 …), 회당 약 N분, 필요한 장비.

## 문구

| 전 | 후 |
|---|---|
| 스쿼트, 벤치프레스은(는) 여기 기구가 없어요 | 사용할 수 없는 운동 2개: 스쿼트, 벤치프레스 |
| 스쿼트, 왜 바꿔요? (별도 시트) | 운동 변경 + 사유 칩 |
| 종목 정정 (한 세트 포함) | 완료 기록 정정 |
| 누가 쓰고 있어요 | 사용 중 |
| 처음 하는 종목이에요… (카드마다) | 세션당 한 번 + '시작값' 표식 |
| 다음 목표 올리기 | 오늘 기록을 다음 기본값에 반영 |
| N번째 운동 완료! | N번째 운동 저장됨 |

## 확인한 것 / 못 한 것

- 390·320px 라이트·다크 스크린샷으로 점검. 320에서 세트 표 열을 줄이되 터치 영역은 44 이상.
- 회귀: 리뷰 1차의 기록 보존 시나리오(교체·정정·오늘만 변경·시간 부족·백업 마이그레이션)는 단위·E2E로 재통과.
- 못 한 것: 아이폰 실기기(음악 재생·잠금 복귀·홈 화면 실행), 글자 확대 200%, 스크린리더 전수 점검. 빌드 식별자는 설정 하단(`v0.3.0 · 빌드 <커밋>`).
