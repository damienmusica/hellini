## 추정 (근거 약함, 앱에 넣지 않음)

- 350평 24시간 체인점이면 보통 스미스 머신, 파워랙 또는 스쿼트랙, 케이블 크로스오버, 레그프레스·핵스쿼트 등 하체 머신, 덤벨 30~40kg대까지는 있다. 브랜드(해머스트렝스·라이프피트니스·사이벡스 등)는 확인 안 됨.
- "인클라인 머신"은 인클라인 체스트 프레스 머신일 가능성이 높다.

## 미확인 — 사용자가 채울 것

조사 환경에서 공식 사이트·당근·네이버 블로그 본문을 직접 열 수 없었고, 검색 요약에 기구 목록은 없었다. 아래를 사진이나 이름표로 보내 주면 `src/data`의 장소 프로필로 넣는다.

- [ ] 프리웨이트: 파워랙/스쿼트랙 대수, 스미스 머신 종류(일반/3D), 벤치 수, 덤벨 최대 무게와 단위(1kg/2kg), 봉 무게(20kg/15kg), 원판 최소 단위(1.25kg 유무)
- [ ] 하체 머신: 레그프레스(45도/수평), 핵스쿼트, 레그 익스텐션, 레그 컬(앉아서/엎드려), 힙 쓰러스트 머신, 어덕션/어브덕션, 카프
- [ ] 가슴·어깨: 체스트 프레스, 인클라인 프레스, 펙덱, 숄더 프레스, 사레레 머신
- [ ] 등: 랫풀다운(머신/케이블), 시티드 로우, 티바 로우, 어시스트 풀업, 케이블 크로스오버 대수
- [ ] 머신 무게 표기: 스택 한 칸이 몇 kg인지(5kg/2.5kg), 원판 로딩식인지
- [ ] 혼잡 시간대(사용 중 교체가 잦은 기구)

## 앱에 반영한 것

- 없음. 기본 장소는 "기구 제한 없음"으로 두고, 운동 중 "기구가 없어요 → 이 장소에서는 항상"으로 직접 쌓을 수 있다.
