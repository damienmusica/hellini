# 헬린이 벤치마크 (2026-10)

v0.2 재설계의 근거. 해외 운동 기록 앱, 한국 초보자 앱, UI 디자인 세 갈래로 조사했다.

> 조사 환경에서 웹페이지를 직접 열 수 없어서, 수치는 검색 결과에 요약된 스토어·공식 사이트·기사 내용을 기준으로 했다. 스토어 수치는 계속 바뀌니 방향만 참고한다.

## 공통으로 꼭 있는 것 → 헬린이 구현

| 패턴 | 헬린이 v0.2 |
|---|---|
| `세트 \| 이전 \| kg \| 회 \| ✓` 표 | 운동 화면의 세트 표. "이전"을 누르면 지난 값 복사 |
| ✓ 하나로 기록·휴식·PR 판정 | ✓ → 체크 애니메이션, 휴식 타이머 자동 시작, PR이면 금색 토스트와 배지 |
| 종목별 휴식 시간, ±15초, 건너뛰기, 화면 밖에서도 보이기 | 하단 플로팅 바(누르면 원형 링), 다른 탭에선 미니 바, 3초 전부터 신호음 |
| 세트 종류 W/D/F, 워밍업은 기록에서 제외 | 세트 번호를 눌러 변경. 워밍업은 볼륨·PR에서 제외, 드롭세트 전엔 쉬지 않음 |
| PR 감지와 완료 화면 요약 | 최고 무게 > 추정 1RM > 최다 반복 > 세트 볼륨 순으로 종목당 하나 |
| 완료 화면: 시간·볼륨·세트·PR·근육 지도·공유 | "N번째 운동 완료!", 숫자가 올라가는 애니메이션, 근육 지도, #오운완 카드(PNG, 공유 시트) |
| 종목별 추이 그래프·기록 | 기록 → 종목별: 추정 1RM 꺾은선, 최고 기록, 날짜별 세트 |
| 라이브러리: 부위·장비 필터, 사용자 정의 종목 | 75개 종목(한국어 이름, 부위, 장비, 주동근·협응근, 한 줄 자세 팁, 유튜브 자세 영상 링크), 초성 검색 |
| 원판·워밍업 계산기 | 종목 메뉴에서 바로 사용 (빈 봉 → 40% → 60% → 80%) |

## 초보자(헬린이)를 위해 고른 것

- **"오늘 뭐 하지"를 없앤다**: 질문 3개(경험, 주당 횟수, 헬스장·집)로 프로그램을 추천한다. 추천 프로그램은 무분할 A/B, 상하체 2분할, 3분할, 5×5, 홈트. 홈에는 다음 차례 루틴을 "오늘의 루틴"으로 띄운다.
- **증량은 제안만 한다**: 지난번에 목표 횟수를 다 채웠으면 "지난번 40kg × 10 성공! 오늘은 45kg 어때요?"를 띄운다. 사용자가 [적용]을 눌러야 바뀐다. 플랜핏의 자동 증량이 부담된다는 불만을 피하려는 선택이다.
- **대체 종목은 무료**: 같은 부위 종목을 먼저 보여준다. 플랜핏이 이걸 유료로 바꿨다가 반발을 산 지점이다.
- **주 단위 목표와 연속 기록**: 일 단위가 아니다. 초보는 쉬는 날이 필요하기 때문이다.
- **해요체 말투**: 짧은 응원 문구와, 1RM·볼륨 같은 용어는 처음 나올 때 풀어서 설명한다.

## 디자인 원칙

- 강조색은 파란색 하나만 쓴다. 색은 상태에만 쓴다: 완료는 초록, PR은 금색, 워밍업은 주황, 시간 세트는 주황.
- 테두리 대신 표면의 단계로 깊이를 낸다. 다크 #0B0B0C → #161618 → #232326.
- 숫자는 전부 Pretendard tabular figures라 타이머가 흔들리지 않는다.
- 큰 ± 스테퍼 대신 칸을 누르면 숫자 키패드가 뜬다. 시스템 키보드가 화면을 밀어 올리지 않고, ±증량 단추와 "다음"이 있다.
- 체크 버튼 스프링, 시트 슬라이드, 토스트, 완료 화면 컨페티(PR이나 기념 회차일 때만). 움직임 줄이기 설정을 따른다.

## 일부러 안 한 것

| 안 한 것 | 이유 |
|---|---|
| 광고, 유료 벽 | 이탈 1순위 원인(JEFIT, 플랜핏) |
| 소셜 피드, 랭킹 | 기록 화면을 가린다는 불만(Hevy), 1인용 앱 |
| AI 채팅 코치, 식단·체성분 | 초보에게 기능 과다 |
| 회복도 % 히트맵 | 체감과 다르다는 불만(Fitbod). 대신 "부위별 마지막 운동 N일 전" |
| 자동 증량 | 신뢰 문제. 제안만 하고 결정은 사용자가 한다 |

## 웹앱(PWA)이라서 생기는 한계

- 아이폰은 진동 API가 없고, 무음 모드에서 효과음이 나지 않는다.
- Live Activity·잠금화면 타이머는 웹에서 불가능하다. 대신 화면 꺼짐 방지(Wake Lock, iOS 18.4+ 홈 화면 앱)를 쓰고, 타이머는 시각 기준으로 계산한다.
- 백그라운드에서 휴식이 끝났다는 알림을 받으려면 서버 푸시가 필요해 보류했다.
