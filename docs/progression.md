# 목표 제안 규칙 v1 · 장소 프로필

2026-10-15 리뷰 리포트 §2·§3·§4를 구현한 내용. LLM 없이 결정 규칙으로 동작한다. 같은 기록·같은 버전이면 같은 제안이 나온다.

## 목표 제안 (`src/lib/progression.ts`, `PROGRESSION_VERSION = 1`)

수치는 보수적인 초안이다. 검증된 운동 처방이 아니라 제품 설계값이며, 실제 기록으로 조정해 버전을 올린다.

### 목표 횟수 범위

계획에 적힌 횟수가 범위의 아래 끝이다.

| 계획 횟수 | 범위 |
|---|---|
| 5회 이하 | 그 횟수 (5×5처럼 채우면 올린다) |
| 6~8회 | +2 (8 → 8~10) |
| 9회 이상 | +3 (10 → 10~13, 12 → 12~15) |

### 최소 증량 단위 (`weightIncrement`)

| 장비 | 단위 |
|---|---|
| 바벨 상체 | 2.5kg |
| 바벨 하체·데드리프트 | 5kg |
| 덤벨 (한 손) | 2kg |
| 머신·스미스 | 5kg |
| 케틀벨 | 4kg |

지금 무게에 단위를 더한다 (7kg 덤벨 → 9kg). 단위의 배수로 반올림하지 않는다.

**보조 중량 종목** (`INVERSE_LOAD`: 어시스트 풀업)은 숫자가 클수록 쉽다. "올리기"는 보조를 단위만큼 줄이기(`less-assist`, 0 아래로는 안 감), 감량은 보조를 단위만큼 늘리기(`deload`)다. 지난 보조는 가장 큰 값(가장 쉬웠던 세트)을 기준으로 삼고, 이미 보조를 더 줄여 계획했으면 제안하지 않는다. 무게·추정 1RM·볼륨 PR은 세지 않고 횟수만 본다(`records.ts`). 기록 기준 표시는 `weightBasisOf`가 "보조 중량 (클수록 쉬움)"으로 바꾼다.

### 규칙 (위에서부터 먼저 맞는 것 하나)

근거는 **같은 장소에서 한 같은 종목의 마지막 기록**(워밍업 제외, 완료한 본세트)이다.

| 조건 | 코드 | 제안 |
|---|---|---|
| 같은 장소 기록 없음 · 지난번 세트를 덜 함 · 오늘 이미 세트를 함 · 이미 더 무겁게 계획함 | — | 없음 |
| 마지막 기록이 21일 이상 전 | `long-gap` | 올리지 않고 지난 무게로 확인 세트 |
| 범위 아래로 끝난 세트가 있고, 직전 기록도 같은 무게 이상에서 그랬음 | `deload` | 10% 줄여서 단위로 내림 |
| 범위 아래로 끝난 세트가 있음 | `hold-missed` | 같은 무게로 한 번 더 |
| 모든 세트가 범위 위쪽 끝 + "거의 한계였어요" | `hold-hard` | 같은 무게로 한 번 더 |
| 모든 세트가 범위 위쪽 끝 | `add-weight` | 무게 + 단위 (맨몸은 횟수 +1) |
| 모든 세트가 범위 위쪽 끝 · 보조 중량 종목 | `less-assist` | 보조 − 단위 |
| 그 외 (범위 안) | `add-reps` | 같은 무게로 세트마다 지난 횟수 +1 (위쪽 끝까지) |

- 세트를 덜 한 날은 실패가 아니다 (시간 부족, 기구 대기). 제안도 감량 근거도 되지 않는다.
- 무게를 올릴 때 세트 수는 건드리지 않는다.
- "여유/적당/한계" 체감은 마지막 세트 뒤에 선택으로 받는다. v1에서는 "한계"만 쓴다(올리기를 한 번 미룸).
- 제안은 운동을 시작할 때 계산해 `ExerciseLog.suggested`에 남긴다: 버전, 코드, 문장, 적용값, 근거 세션 id, 적용·닫기 여부. 기록을 정정해도 당시 제안은 그대로 남는다.
- 정체: 같은 장소에서 3번 연속 최고 세트가 같으면 종목 상세에 알려만 준다. 세트 수·분할 변경은 사용자가 정한다.

## 장소 프로필 (`src/lib/places.ts`)

- 기본 장소 `main`(평소 헬스장)은 장비 제한이 없다. 장소가 없는 옛 기록은 기본 장소로 본다.
- 홈의 장소 칩에서 고른다: 저장한 장소 / 다른 곳(장비 체크, 등록 없이) / 맨몸만. 임시 장소는 운동을 마치면 지워지고 평소 헬스장으로 돌아온다.
- 장소 사본(`id`, 이름, 장비)이 세션에 남는다. 장소를 지우거나 이름을 바꿔도 기록은 그대로다.
- 이 장소에 없는 기구 종목은 운동 화면에서 표시하고, 대체 추천은 없는 기구를 점수 전에 뺀다. 보조 장비(`Feature`)는 벤치·인클라인 벤치·랙·풀업바·백익스텐션 벤치. 백 익스텐션은 전용 벤치가 있어야 하고, 바닥 변형(`floor-back-extension`)은 맨몸이다.
- 장비 목록이 없는 장소(`equipment`·`features` 미지정 = 기본 장소)는 "모름 = 전부 가능"으로 보고, 목록이 있는 장소는 고른 것만 있다고 본다. 임시 장소는 아무것도 고르지 않은 상태에서 시작한다.
- 후보 카드의 "다른 점"은 데이터로 계산한다(`diffOf`): 역할 변화 → 더 필요한 보조 장비 → 기록 기준 → 편측 → 장비, 최대 3개. 무게·횟수의 동등성은 주장하지 않는다.
- 종목을 바꿀 때 이유를 받는다: 기구 없음 / 사용 중(뒤로 미루기 또는 다른 종목) / 다른 운동. 이유는 기록(`swap`)에 남는다.
- 적용 범위: 기본은 오늘만. 등록된 장소에서 "기구 없음"으로 바꾸면 "이 장소에서는 항상"을 고를 수 있다 (장소 프로필에 `unavailable`·`swaps`). 기본 루틴 변경은 마칠 때 따로 고른다.
- 무게는 옮기지 않는다: 새 종목의 무게는 그 종목의 **이 장소** 기록, 없으면 시작값.
- 대체 추천의 적격성·중복 금지·후보 없음 규칙은 `docs/design.md` v3.1(`src/lib/adjust.ts`). "이전" 칸은 다른 장소 기록을 보여주되 그렇다고 표시한다.
- 다른 장소에서 한 운동은 마칠 때 "다음 목표 올리기"가 기본으로 꺼진다.

## 주간 리뷰 (`src/lib/review.ts`, `REVIEW_VERSION = 1`)

대상 주(기본: 지난 주, 월~일)의 세션만 본다. 충족한 조건만 문장으로 만든다.

| 조건 | 코드 | 문장 |
|---|---|---|
| 세션 0 | `no-session` | 지난 주는 기록이 없어요. 이번 주는 1회부터 |
| 세션 ≥ 주간 목표 | `goal-met` | 주 N회 목표를 채웠어요 |
| 세션 < 목표 | `goal-short` | 목표 N회 중 n회. 빠진 날은 실패가 아니라 다음 주 첫 운동 자리 |
| 전주 볼륨이 있고 ±15% 이상 | `volume` | 전주 대비 +x% / −x% (운동 횟수가 줄었으면 같이 표시) |
| 새 기록 ≥ 1 | `prs` | 새 기록 n개 |
| 밀기·당기기·하체 합 ≥ 15세트이고 한쪽이 가장 많은 쪽의 절반 아래 | `balance` | A n세트 vs B m세트. 다음 주엔 A 날을 먼저 |
| 연속 주 ≥ 2 | `streak` | n주 연속 |
| 체중 기록 둘 이상(7일 이상 간격, 6주 안) | `body` | `bodyTrend` 문장 그대로 |
| 다음 루틴 있음 | `next` | 다음 차례 · 루틴 |

- 볼륨 숫자는 카드 위 숫자 행에 있으므로 전주 비교가 없을 땐 문장으로 반복하지 않는다.
- 홈 노출: 지난 주나 그 전주에 기록이 있고, 이번 주에 아직 닫지 않았을 때(`settings.reviewSeenWeek`).

## 체성분·프로필 (`src/lib/body.ts`)

사용자가 인바디 수치를 넣으면 쓰는 것. 전부 선택이고 이 기기에만 저장된다(백업 파일에 포함).

- **기록**: 날짜, 체중(필수), 체지방률, 골격근량, 허리둘레, 메모. 기록 탭 → 몸.
- **프로필**: 성별, 출생연도, 키, 지금 단계(리컴프 / 린벌크 / 감량 / 유지).
- **단계 추천** (`recommendGoal`): 체지방률 기준. 남 20% / 여 28% 이상이면 리컴프(열량을 더 넣으면 지방부터 붙으므로), +5%p 이상이면 감량, 남 15% / 여 22% 이하면 린벌크. 적용은 사용자가 누른다.
- **영양 목표** (`nutritionTargets`): 체지방률이 있으면 Katch-McArdle(370 + 21.6 × 제지방량), 없으면 Mifflin-St Jeor(성별·나이·키). 활동 계수는 주간 목표 횟수로(≤2회 1.3, 3회 1.375, 4~5회 1.5, 6회+ 1.6). 단계별 가감: 리컴프·유지 0, 린벌크 +250, 감량 −400. 단백질 체중 kg당 1.8g(감량 2.0g), 5g 단위. 출발점일 뿐이고 추세로 맞춘다.
- **체중 추세** (`bodyTrend`): 최근 6주 안에서 7일 이상 떨어진 두 기록의 주당 변화율. 린벌크 +0.15~0.75%, 감량 −0.25~−1.2%, 리컴프·유지 ±0.35%를 정상으로 보고 벗어나면 한 줄 조언(하루 100~150kcal 가감).
- **체중 대비 근력** (`strengthLevel`): 벤치·스쿼트·데드·OHP·바벨 로우의 추정 1RM ÷ 체중. 대략적인 기준표(남/여)로 입문·초급·중급·상급과 다음 단계까지 필요한 1RM을 보여준다.
- **재측정 알림**: 마지막 기록이 90일 넘으면 홈에 배너.
- **세트·무게 제안은 체성분을 쓰지 않는다.** 리뷰 §4 원칙(체중만으로 작업 중량을 산출하지 않는다)대로, 체중은 영양·추세·상대 근력에만 쓴다.
